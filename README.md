# Flight Ticket Price Prediction

#### -- Project Status: [Active]

## Project Intro/Objective
The purpose of this project is the building and creation of a machine learning regression model for the prediction of airline ticket prices using the previous prices and the factors surrounding them..

### Methods Used
* Machine Learning
* Data Visualization
* Feature Engineering
* Predictive Modeling

### Technologies
* Python
* Pandas
* Numpy
* Seaborn
* Plotly

## Project Description

 
## Needs of this project

- Fine-tune prices to stay competitive without leaving money on the table.
- Help customers book flights at the best possible price.
- Maximize revenue by predicting demand and adjusting prices accordingly.
- Spot peak travel times so you never miss an opportunity to sell.
- Stay one step ahead of competitors with smarter pricing strategies.
- Offer personalized deals to customers based on when they’re likely to buy.
- Make smarter business decisions by using data to cut unnecessary costs.
